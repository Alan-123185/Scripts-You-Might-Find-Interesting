# 刷课脚本

这是一个基于 Playwright 的学习页面自动化示例。脚本打开指定课程页，按顺序点击二级标题，在页面及其 iframe 中查找视频播放按钮并播放视频；通过检查 `<video>` 元素的 `ended` 状态判断当前视频是否结束，并用 Loguru 输出过程信息。

## 运行说明

安装依赖和 Chromium 浏览器：

```powershell
pip install playwright loguru
playwright install chromium
```

运行脚本：

```powershell
python 刷课脚本.py
```

脚本从 `asyncio.run(main(argv=4))` 指定的位置开始处理；索引从 `0` 开始，因此 `4` 表示第五个二级标题。修改这里的数字可以调整起始位置。

登录状态从用户主目录下的 `.classScropt-playwright-state.json` 读取，并在脚本结束前保存。状态文件包含登录凭据相关信息，不要分享或提交到版本库。登录状态缺失或过期时，脚本目前没有自动识别和处理登录失效的逻辑。

脚本只适用于当前页面结构和选择器。网页改版、课程内容变化或视频未正常播放时，运行结果可能与预期不同；遵守网站规则，并仅在有权限的页面使用。

## 学银在线页面元素定位记录

以下是脚本当前使用的页面结构观察，适用于本脚本访问的课程学习页面；网站更新后需要重新检查。

- 页面左侧的二级标题使用 `.posCatalog_name` 定位。脚本按列表顺序点击标题，并读取 `title` 属性作为日志中的章节名称。
- 点击标题后，视频区域需要一段时间加载。当前脚本固定等待 5 秒；如果章节切换较慢，后续查找可能早于播放器加载完成。
- 播放器不一定在主页面，而是在 iframe 中。脚本遍历 `page.frames`，并在每个 frame 内查找 `button.vjs-big-play-button`；调试时记录 frame 序号、名称和匹配数量。
- 找到播放按钮后，在同一个 frame 内定位 `video` 元素。脚本轮询 `video.ended` 判断视频是否播放完；`video.paused` 用来记录暂停情况。找不到播放按钮时会记录警告并跳过该标题。
- 如果页面改版后定位失效，先确认标题选择器是否仍匹配，再检查视频 iframe 是否加载、frame 内播放按钮是否仍存在。不要只根据屏幕位置推测元素归属。
